Pasos para hacer pasta

  1. Llena 2/3 de una olla grande con agua.
  2. Cubre a olla y pon el agua a hervir.
  3. Añade sal y 450g de pasta en el agua hirviendo.
  4. Programa un temporizador de 3 a 8 minutos.
  5. Revuelve los fideos de vez en cuando mientras hiervan.
  6. Prueba un fideo para ver si esta lo suficientemente cocido para ti.

LISTAS DESCRIPTIVAS

Tipos de juegos

RTS(Real-time Strategy)
Tipo de juego de estrategia en tiempo real donde las acciones ocurren sin pausas
El jugador debe gestionar recursos como oro, madera o energia.
Se trata en construri bases, crear unidades y expandir territorio.
MOBA(Multiplayer Online Battle Arena)
Juego multijugador en equipos donde cada jugador cumple un rol específico.
El objetivo suele ser destruir la base enemiga usando estrategia y trabajo en equipo.
Cada personaje tiene habilidades únicas que se mejoran durante la partida.
FPS(First Person Shooter).
Juegos de disparos en primera persona.
Se enfoca en la precisión, reflejos y combate en tiempo real.
Puede tener modos multijugador o campañas individuales.

Lenguajes de programacion Web

HTML
Lenguaje de marcado que define la estructura de una página web.
Permite agregar textos, imagenes, enlaces y listas.
Es la base de cualquier sitio web.
CSS
Lenguaje que se usa para diseñar y dar estilo a las páginas web.
Controla colores, tamaños, márgenes, posiciones.
Permite crear diseños atractivos y adaptables a diferentes dispositivos.
JavaScript
Permite agregar interactividad a una página web.
Se usa para botones, animaciones, validaciones de formularios y eventos.
Puede modificar el contenido HTML en tiempo real.
